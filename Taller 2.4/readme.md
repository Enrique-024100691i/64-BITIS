# README - IntrasevMotors

## Descripcion del Proyecto
IntrasevMotors es un sistema de escritorio orientado a la gestion integral de ventas, inventario y compras de una empresa distribuidora de repuestos y motores para vehiculos. El sistema resuelve problemas reales como el seguimiento de stock en tiempo real, el registro automatizado de ventas con calculo de totales y el control de ordenes de compra a proveedores.
