Taller 2.2. Join

Descripción del Proyecto
Este proyecto tiene como objetivo aplicar el uso de INNER JOIN, LEFT JOIN y RIGHT JOIN en bases de datos relacionales, específicamente en las bases de datos Pubs y Northwind.
Se desarrollaron consultas SQL orientadas a resolver problemas de negocio reales como ventas, relaciones entre entidades y detección de registros sin correspondencia.
