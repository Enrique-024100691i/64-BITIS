Intrasev Motors

Una arquitectura relacional desarrollada para gestionar el inventario, ventas y clientes de una empresa de repuestos automotrices de alta gama en Cusco, Perú.

{/* Sección 1: El Contexto */}

El Contexto

Intrasev Motors es especialista en el suministro de motores y repuestos para vehículos de lujo (Audi, BMW, Mercedes-Benz). Con el aumento de las transacciones y el alto valor del inventario, la gestión manual se volvió insostenible.

El Desafío: Crear un sistema estructurado para vincular de manera exacta el catálogo de productos premium con las ventas realizadas, los clientes y los empleados responsables.

Conclusión del Proyecto

El modelo conceptual centraliza y organiza eficientemente la información crítica de la empresa. Al establecer una trazabilidad estructurada entre clientes, ventas y asesores, el sistema previene rupturas de stock, facilita el análisis del historial de compras y sienta unas bases tecnológicas sólidas y altamente escalables.
