Introducción

En la actualidad, la transformación digital es un paso obligatorio para las empresas. Este informe detalla el diseño del Modelo Conceptual de Base de Datos para la empresa Intrasev Motors, aplicando fundamentos de bases de datos relacionales para optimizar la gestión de inventario y ventas.

¿Qué es Intrasev Motors?

Ubicada en Cusco, se dedica a la comercialización de motores y repuestos para vehículos de alta gama (Audi, BMW, Mercedes-Benz). El reto principal es organizar eficientemente su inventario de alto valor y vincularlo con las ventas y el desempeño de sus empleados.

Sector Automotriz Premium

Requerimientos del Negocio

REQ-01: Inventario

Catálogo de motores, categorías, marcas compatibles y control de stock.

REQ-02: Clientes

Registro de DNI/RUC, razón social y contacto para facturación.

REQ-03: Empleados

Trazabilidad de asesores comerciales por cada transacción.

Arquitectura del Modelo

Implementación Física (SQL Server)

-- CREACIÓN DE LA BASE DE DATOS CREATE DATABASE IntrasevMotors; GO USE IntrasevMotors; -- TABLA PRODUCTO CREATE TABLE Producto ( ID_Producto INT PRIMARY KEY IDENTITY(1,1), Nombre_Producto VARCHAR(150) NOT NULL, Categoria VARCHAR(50) NOT NULL, Marca_Compatible VARCHAR(50), Precio DECIMAL(10,2) NOT NULL, Stock INT NOT NULL ); -- TABLA DETALLE VENTA (ENTIDAD PUENTE) CREATE TABLE Detalle_Venta ( ID_Detalle INT PRIMARY KEY IDENTITY(1,1), ID_Venta INT NOT NULL, ID_Producto INT NOT NULL, Cantidad INT NOT NULL, Subtotal DECIMAL(10,2) );

Conclusión

El modelo diseñado centraliza eficientemente la información crítica, eliminando redundancias. La solidez técnica de la entidad puente "Detalle_Venta" garantiza una arquitectura escalable, sentando las bases tecnológicas para la transformación digital de Intrasev Motors.
