El Contexto: Intrasev Motors

Empresa del sector automotriz en Cusco especializada en la comercialización de motores y repuestos para vehículos de alta gama (Audi, BMW, Mercedes-Benz).

El Desafío

Al manejar un inventario de alto valor, necesitan un sistema estructurado para vincular su catálogo premium con las ventas, clientes y empleados. La transformación digital es un paso obligatorio.

Requerimientos del Negocio

REQ-01: Inventario

Almacenar el catálogo de motores y repuestos (categoría, marcas compatibles, precios) y llevar un control estricto de stock.

REQ-02: Clientes

Registrar información fiscal (DNI/RUC, Razón Social) y de contacto para procesos de facturación y fidelización.

REQ-03: Empleados

Trazabilidad en cada transacción para saber qué asesor comercial gestionó la venta y así medir su rendimiento.

REQ-04: Control de Ventas

Registrar la factura general y permitir el desglose en múltiples productos (Detalle de Venta) con cantidades y subtotales.

REQ-05: Reglas

El sistema tiene bloqueado el registro de ventas con montos totales en cero o en valores negativos para asegurar la integridad.

Entidades y Atributos

Estructura fundamental de la base de datos de Intrasev Motors, identificando claves primarias (PK) y foráneas (FK).

Cliente
  • IdCliente PK
  • Razon_Social_Nombre
  • DNI_RUC
  • Telefono
  • Correo
  • Direccion
Empleado
  • IdEmpleado PK
  • Nombre_Completo
  • Cargo
  • Telefono
Producto
  • IdProducto PK
  • Nombre_Producto
  • Categoria
  • Marca_Compatible
  • Precio
  • Stock
Venta (Cabecera)
  • IdVenta PK
  • Fecha_Venta
  • Total
  • IdCliente FK
  • IdEmpleado FK
Detalle_Venta (Entidad Puente)
  • IdDetalleVenta PK
  • IdVenta FK
  • IdProducto FK
  • Cantidad
  • PrecioUnitario
  • Subtotal

Nota de diseño: La tabla puente Detalle_Venta rompe exitosamente la relación de "muchos a muchos" (N:M) entre Ventas y Productos, normalizando la base de datos.

Relaciones y Cardinalidades

Cliente 1 : N Venta

Un cliente realiza múltiples compras, pero una factura pertenece a un solo cliente.

Empleado 1 : N Venta

Un asesor gestiona muchas ventas, pero una venta específica es comisionada a un solo empleado.

Venta 1 : N Detalle_Venta

Una factura contiene múltiples líneas de productos, pero un detalle pertenece única y exclusivamente a esa factura.

Producto 1 : N Detalle_Venta

Un repuesto del inventario aparece en múltiples ventas, pero una línea de detalle refiere a un único producto del catálogo.

Conclusión y Beneficios

El modelo diseñado centraliza y organiza eficientemente la información crítica, eliminando redundancias. Al establecer esta trazabilidad, el sistema abre nuevas oportunidades para estrategias de fidelización y marketing, y sienta las bases tecnológicas para soportar la futura transformación digital de Intrasev Motors.
