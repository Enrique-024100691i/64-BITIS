Procedimientos Almacenados en Oracle

Caso de Estudio: Intrasev Motors

Univ. Andina del Cusco Grupo 64 bits

Contexto del Proyecto

Intrasev Motors es una empresa dedicada a la venta de repuestos de vehículos que busca optimizar la gestión de su información mediante el uso de bases de datos relacionales en Oracle.

Objetivo Principal:

"Implementar procedimientos almacenados para centralizar la lógica del negocio, mejorar la seguridad y automatizar tareas críticas en el Datacenter."

Entidades Clave

  • Clientes
  • Productos (Repuestos)
  • Ventas
  • Personal de Ventas

Escenarios en el Datacenter

1

Registro de Clientes

Validación de datos de entrada antes de la inserción para asegurar la integridad de los contactos de ventas.

PROCEDURE registrar_cliente(...)
2

Consulta de Ventas

Extracción rápida de reportes históricos para que los gerentes tomen decisiones basadas en datos reales.

PROCEDURE consultar_ventas(...)
3

Gestión de Stock

Actualización automática del inventario tras cada transacción, evitando sobreventa de repuestos.

PROCEDURE actualizar_stock(...)

¿Por qué usar Stored Procedures?

Seguridad

Evita SQL Injection y oculta la estructura de tablas.

Rendimiento

Reduce el tráfico de red enviando solo una llamada.

Integridad

Centraliza las reglas de negocio en un solo lugar.

Mantenimiento

Cambios en la lógica no requieren recompilar el frontend.

Conclusiones

La implementación de PL/SQL en Intrasev Motors garantiza un entorno robusto y escalable. Se logró optimizar las operaciones de ventas y el control riguroso del inventario de repuestos.

Recomendaciones

  • Implementar un plan de copias de seguridad automatizadas.
  • Desarrollar un Frontend (Java/C#) para el personal de ventas.
  • Realizar mantenimiento preventivo periódico al servidor Oracle.
